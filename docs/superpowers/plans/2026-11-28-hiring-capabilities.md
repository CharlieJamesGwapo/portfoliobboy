# Hiring Capabilities Implementation Plan

> **For agentic workers:** Use the existing implementation workflow, with independent skills and automation tasks delegated under superpowers:dispatching-parallel-agents and a fresh final review.

**Goal:** Make AWS/DevOps, AI automation and custom-bot capabilities discoverable and detailed while preserving truthful project counts and existing conversion flows.

**Architecture:** Existing React/Vite data-driven sections. Skills owner edits portfolio skill data and Skills UI/styles; automation owner edits automation data and catalogue UI/styles; root integrates service links, Alex answers, verification and release.

**Tech Stack:** React 18, CSS, Vite, Node 24, Playwright, Vercel.

**Spec:** `docs/superpowers/specs/2026-11-28-hiring-capabilities-design.md`

## Constraints

Do not fabricate project counts, credentials or unsupported experience. No real messages, bots, calls, bookings, new dependencies/paid services, provider changes or deletions. Preserve theme/accessibility/mobile performance, contact privacy and current monitoring. Root alone owns shared builds, commits, push and deployment.

## Tasks

- [x] Expand supported skill groups with visible AWS/DevOps and project evidence, preserving keyboard behavior and bounded mobile layout.
- [x] Expand the automation catalogue with detailed service patterns, clear status, filters/search, initial six-card limit, disclosure, reset and editable enquiry actions.
- [x] Update Services/Alex to reflect the new catalogue and cloud/bot scope without inventing delivery claims; retain 22+ documented builds pending a confirmed larger count.
- [x] Review content/trust boundaries and links; run full tests/build, relevant browser suites and a fresh review; document results.
- [x] Commit/push, verify CI and production deployment, run live security checks and inspect the updated sections.

## Review focus

- A platform/service pattern is not proof of a deployed project or expert proficiency.
- Empty searches, combined filters and changing categories must keep counts and focus understandable.
- New evidence links must resolve to public portfolio routes and match the stated capability.
- Enquiry actions must stage editable context and never send, discard an existing draft or start voice.
- The larger catalogue must not cause initial optional-engine downloads, horizontal overflow or lengthy blocked interactions.
